# 02_Synthetics — 2차 창작 아카이브

평범하고 따뜻한 일상을 담은 그래픽 작업물을 모아 두는 곳입니다.

## 넣는 기준

- `01_Concepts/Character_Bible.md` 의 "해야 할 것 / 하지 않을 것" 을 따르는 작업물만.
- 출처(만든 사람, 사용한 도구, 원본 링크)를 알 수 있는 것만. AI 생성 이미지는 사용한 모델과 프롬프트를 함께 기록합니다.
- 실존 인물의 얼굴·사진을 합성한 이미지는 넣지 않습니다.

## 파일 이름

`YYYYMMDD_장면_작성자.확장자` — 예: `20261101_pizza_night_haven.png`
